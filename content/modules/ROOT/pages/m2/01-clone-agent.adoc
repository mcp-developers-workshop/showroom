= The Complaint Agent Repository
:numbered:
:icons: font
:source-highlighter: highlight.js

The agent you connect to your MCP server in this module already exists. It is called Glo. Clone it from GitLab so you can work on it in IBM Bob.

== Open the repository

Open the `globex-complaint-agent` folder in a separate IBM Bob window. You have already cloned it from GitLab. See xref:dev-setup/03-open-in-bob.adoc[Open a Repository in IBM Bob].

Leave `globex-store-mcp` open in its own window - Module 1's dev mode and MCP Inspector may still be running there, and the agent needs that MCP server up.

== What is in the repository

A small Quarkus application with three classes:

* `AgentResource` — HTTP entry point at `/api/v1/request`. Takes a complaint request and user identity, passes them to the service.
* `ComplaintService` — Forwards the request to the agent. This is where you'll add behavior in this module.
* `ComplaintAgent` — A LangChain4j AI service that handles the conversation. Uses a system prompt to guide the agent to ask for order ID, product code, issue description, and severity.

The agent is configured to use OpenAI in `application.properties`, with request/response logging enabled for debugging.

[IMPORTANT]
====
The agent has no tools yet. It can hold a conversation but cannot look up orders. Giving it your MCP server tools is what this module is about.
====
