= Module 2: Expand Agent Capability with MCP Server
:numbered:
:icons: font
:source-highlighter: highlight.js

== Overview & Objectives
An agent that handles product complaints already exists, but it has no tools: it can hold the conversation and nothing more. In this module you connect it to the MCP server you built in Module 1 and to a second MCP server that files complaints, then deploy the result to OpenShift.

=== Learning Objectives
* Understand agentic tool discovery and dynamic tool registration via MCP.
* Configure an MCP client, and know which of its settings are fixed when the application is built and which are read at startup.
* Modify system prompts to guide the agent in selecting appropriate tools.
* Carry the signed-in user's identity from a verified token through to every MCP tool call.
* Test agent interactions locally before deploying updates to OpenShift.

== Architecture & Components
* *AI Agent:* Globex Complaints & Order Assistant (LangChain4j / Quarkus Agent)
* *MCP Servers:* Order History MCP Server (Module 1) & Complaints MCP Server
* *Front end:* Angular chatbot, run locally, signing in against Keycloak
* *Configuration:* `application.properties` and `.env` locally, a Helm chart rendering a Kubernetes Secret once deployed
* *Deployment Pipeline:* GitLab, OpenShift build, ArgoCD Sync

== Prerequisites
* Successful completion of Module 1 (Order History MCP Server deployed)
* Local development environment with Java 21 / Quarkus runtime
* Access to OpenShift namespace secrets and deployment tools

== Lab Agenda
1. Clone the complaint agent and read through the code you are about to change
2. Connect the agent to the model with the Quarkus OpenAI extension and an API key
3. Give the agent the orders tool from the MCP server you built in Module 1
4. Test the agent from a chatbot front end running on your machine
5. Send the signed-in user's ID with every MCP tool call
6. Give the agent the complaints tool so it can file the complaint
7. Deploy the agent to OpenShift and test it there

== Expected Outcomes
An AI agent running on OpenShift capable of dynamically calling external MCP server tools to resolve user queries and handle order history and complaint actions.
