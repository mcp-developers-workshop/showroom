= Set Up the Workshop Environment
:numbered:
:icons: font

== Log in to GitLab

The workshop environment includes a GitLab instance. You will push your MCP server to it later in this module, and ArgoCD deploys from it.

Open https://gitlab-gitlab.{openshift_subdomain}[GitLab^].

Sign in with the workshop developer account:

image::m1/gitlab-login.png[link=self,window=_blank]

[cols="1,2", options="header"]
|===
| Field | Value

| Username
| `developer`

| Password
| `{common_password}`
|===

[NOTE]
====
The workshop cluster uses a self-signed certificate. Accept the browser warning if you see one.
====

You land on the GitLab *Projects* dashboard.

== Open IBM Bob and Clone the Repository

*IBM Bob* is the AI code assistant used throughout this workshop.

=== Open IBM Bob

On the desktop of your workshop VM, double-click the *IBM Bob* shortcut and wait for the workbench to load.

=== Give Bob the Quarkus tooling

In the next section you ask Bob to generate a Quarkus MCP server. Register the Quarkus MCP server with Bob first, so it has tools for creating the project and adding extensions rather than writing the files from memory.

Type this into the *New Task* box in the *IBM BOB* panel, not into a terminal:

[source,text,role="copypaste"]
----
mcp add quarkus-agent -- jbang quarkus-agent-mcp@quarkusio
----

image::m1/bob-mcp-add.png[link=self,window=_blank]


=== Create and open the workshop folder

1. Select *File* -> *Open Folder*.
2. Create a new folder called `workshop` in your home directory.
3. Select the `workshop` folder and confirm to open it.

Bob reloads with `workshop` as the active folder.

=== Clone the Globex MCP repository

Open a terminal inside IBM Bob (*Terminal* -> *New Terminal*). It opens in the `workshop` folder.

[source,sh,role="copypaste",subs="attributes+"]
----
git clone https://gitlab-gitlab.{openshift_subdomain}/globex/globex-store-mcp.git
----

[NOTE]
====
`globex-store-mcp` holds only a few starter files at this point. You build the MCP server into it over the next sections and push it back to GitLab.
====

Confirm the folder is in place:

[source,sh,role="copypaste"]
----
cd globex-store-mcp && ls -la
----

You should see a listing for the cloned folder.
