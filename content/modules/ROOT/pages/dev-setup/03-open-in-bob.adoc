= Open a Repository in IBM Bob
:icons: font
:source-highlighter: highlight.js

Each module tells you which repository to work in. Open it when you get there, not before.

. If Bob is not already running, double-click the *IBM Bob* shortcut on the desktop of your workshop VM and wait for the workbench to load.

. On the Bob welcome page, under *Start*, click *Open...* and choose the folder from `~/mcp-workshop`. From a window that already has a folder open, use *File* -> *Open Folder* so each repository keeps its own window.

. The folder opens in *Restricted Mode* -- a banner across the top, and *Restricted Mode* and *Java: Lightweight Mode* in the status bar. Click *Manage* in the banner, then *Trust*.
+
image::dev-setup/bob-workspace-trust.png[link=self,window=_blank]
+
[IMPORTANT]
====
Trust the folder before you do anything else in it. While it is restricted, tasks are not allowed to run, debugging is disabled, and 24 extensions -- the Quarkus and Java tooling among them -- are inactive.

Trust applies to one folder. You do this once per repository, as you open each one.
====
