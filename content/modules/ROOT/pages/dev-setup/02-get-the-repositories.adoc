= Get the Workshop Repositories
:icons: font
:source-highlighter: highlight.js

Six repositories are used across Modules 1, 2, 3 and 5. Clone them all now, into one folder, so they sit side by side.

Open a Terminal in your Development Environment and run:

[source,sh,role="copypaste",subs="attributes+"]
----
mkdir -p ~/mcp-workshop && cd ~/mcp-workshop
git clone https://gitlab-gitlab.{openshift_subdomain}/globex/globex-store-mcp.git
git clone https://gitlab-gitlab.{openshift_subdomain}/globex/globex-complaint-agent.git
git clone https://gitlab-gitlab.{openshift_subdomain}/globex/globex-complaint-agent-helm.git
git clone https://gitlab-gitlab.{openshift_subdomain}/globex/globex-complaints.git
git clone https://gitlab-gitlab.{openshift_subdomain}/globex/globex-complaints-orchestrate.git
git clone https://github.com/mcp-developers-workshop/mcp-workshop-chatbot.git
----

None of these ask for credentials. Reading is anonymous on both GitLab and GitHub here; you sign in the first time you *push*, in Module 1.
