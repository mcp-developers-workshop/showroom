== Executive Summary & Vision
Welcome to the *MCP in Practice for Developers* hands-on workshop. This workshop is engineered to guide software architects, platform engineers, and developers from initial local prototyping ("laptops") to deploying secure, observable, and enterprise-ready Model Context Protocol (MCP) servers and AI agents in production ("production").

As enterprises rush to adopt Generative AI and agentic workflows, connecting LLM agents directly to backend infrastructure introduces significant security, governance, and architectural challenges. This workshop demonstrates how to use the *Model Context Protocol (MCP)* as a standardized control plane that exposes intent rather than raw resources, enforces zero-trust boundaries, and integrates cleanly with modern enterprise platforms like Red Hat OpenShift.

== The Enterprise Challenge
Enterprise software teams face a converging storm of demands:

* *Accelerated Application Modernization:* 80% of enterprise technologists plan to modernize more than half of their legacy applications within two years [1].
* *Developer Cognitive Overload:* 76% of organizations cite high cognitive load and fragmented tooling as a primary cause of low developer productivity [1].
* *Rapid AI Agent Adoption:* 80% of enterprise applications are projected to incorporate Generative AI and agentic capabilities by 2026 [1].
* *The Agent Security Gap:* Directly exposing REST APIs or databases to AI agents leads to data over-fetching, credential exposure, and prompt injection vulnerabilities [1].

== The Solution: Model Context Protocol (MCP)
This workshop addresses these challenges by establishing an *Intentional Agent Architecture*:

1. *Exposing Intent over Resources:* Standardize agent capabilities into well-defined MCP tools rather than granting raw API access [1].
2. *Data Minimization & Sanitization:* Filter and massage backend payloads before they enter the LLM context window.
3. *Zero-Trust Security & Identity:* Authenticate agents using cryptographic SPIFFE/SPIRE workload identities and Keycloak OIDC service accounts.
4. *Centralized Governance:* Control tool sprawl using an enterprise MCP Gateway (ContextForge) with fine-grained policy enforcement.
5. *Full-Stack Observability:* Audit agent execution, trace LLM calls, and monitor system health with LangFuse and the LGTM stack.

== Environment & Architecture Overview

During this workshop, you will work within a dedicated Red Hat OpenShift Sandbox environment equipped with:

* *OpenShift Cluster Namespace:* Pre-provisioned workspace for building, running, and deploying microservices.
* *Quarkus Runtime & AI Assistance:* Modern Java framework with Quarkus MCP extensions and AI-assisted developer tooling.
* *Keycloak IAM & SPIRE Provider:* Identity management pre-configured for OIDC service accounts and native SPIFFE workload attestation.
* *Observability Suite:* Pre-installed LangFuse instance and LGTM telemetry stack with pre-built Grafana dashboards.
* *ContextForge MCP Gateway:* Centralized proxy and policy engine for managing agent-to-server connections.
