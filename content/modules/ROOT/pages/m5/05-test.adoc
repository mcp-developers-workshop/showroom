= Test the Agent

:numbered:
:icons: font
:source-highlighter: highlight.js

== Confirm the agent is deployed

[source,bash,role=execute]
----
orchestrate agents list
----

`complaints_analyser` should appear as deployed.

== Ask for a product improvement report

Start a chat with the agent:

[source,bash,role=execute]
----
orchestrate chat start -a complaints_analyser
----

Then send the request:

[source,text,role=copypaste]
----
Based on the last 100 complaints, give me a prioritised list of product improvements.
----

This is the fifth starter prompt, so you can also click it in the chat UI rather than typing it.

== What the agent does

Watch the tool calls in the reply. The agent works through them in order:

. `list_tables` and `describe_tables`, to find the `complaints` table and learn that it has `issue_type`, `severity`, `status`, and `created_at` columns.
. `read_query`, to pull the 100 most recent complaints ordered by `created_at`, and to group them by issue type and severity.
. Its own reasoning over the result, to turn the counts into a ranked list of improvements.

The reply should be a prioritised list -- the recurring issue types, ordered by volume and severity, each with the change it implies. It is displayed in the chat and nothing is written anywhere.
