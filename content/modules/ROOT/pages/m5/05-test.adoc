= Test the Agent

:numbered:
:icons: font
:source-highlighter: highlight.js

== Confirm the agent is deployed

[source,bash,role=execute]
----
orchestrate agents list
----

`complaints_analyser` should appear as deployed.

== Chat with the agent

[source,bash,role=execute]
----
orchestrate chat start -a complaints_analyser -m "Show me a breakdown of complaints by severity."
----

The agent calls `list_tables` and `describe_tables` to inspect the schema, then `read_query` to run the query, and summarises the result. A reply that contains counts by severity confirms the whole chain works: agent to toolkit, toolkit to MCP server, and the connection's OAuth token to Keycloak.
