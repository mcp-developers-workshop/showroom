= Test the Agent
:numbered:
:icons: font
:source-highlighter: highlight.js

== Step 1: Confirm it is deployed

[source,sh,role="copypaste"]
----
orchestrate agents list
----

`complaints_analyser` should appear as deployed. You may see other agents too.

== Step 2: Chat with the agent

[source,sh,role="copypaste"]
----
orchestrate chat ask --agent-name complaints_analyser --include-reasoning
----

That opens an interactive session. `--include-reasoning` prints the tool calls as the agent makes them; without it you get the answer only.

Ask for a report:

[source,text,role="copypaste"]
----
Give me a product improvement report based on the last 100 complaints.
----

Or use the web UI. Open it with *Launch watsonx Orchestrate* on the instance page in IBM Cloud -- the same page you took the credentials from in xref:m5/01-setup.adoc[Set Up Orchestrate] -- then select *Complaints Analyser* and click the relevant starter prompt.

== Troubleshooting

[cols="1,2", options="header"]
|===
| Symptom | Fix

| `401 Unauthorized` when registering the toolkit
| The connection has no valid credentials. Re-run `orchestrate connections set-credentials` with the correct client ID, secret and token URL, then register the toolkit again.

| `Token expired`
| Run `orchestrate env activate globex` and paste your API key again.

| `Tool not found` when the agent runs
| Run `orchestrate tools list` and check the names in the agent YAML match it exactly, including the `globex-complaints:` prefix.

| The agent answers without calling any tools, or says it has no data
| The toolkit tools are not reaching the agent. Same check as above.
|===
