= Set Up Orchestrate

:numbered:
:icons: font
:source-highlighter: highlight.js

You put the Globex complaints MCP server behind a watsonx Orchestrate agent with three artefacts: a *connection* that authenticates to Keycloak, an *MCP toolkit* that registers the remote server, and a *native agent* that uses its tools.

== Get your Orchestrate credentials

Your watsonx Orchestrate instance is in the same IBM TechZone reservation as watsonx.ai. Sign in to IBM Cloud with the reservation's login URL and student credentials, as you did in xref:dev-setup/04-watsonx.adoc[Set Up watsonx.ai], and open the *Resource list*.

Under *AI / Machine Learning*, open the row whose *Product* is *watsonx Orchestrate* -- its name starts `itz-wxo-`.

image::m5/orchestrate-resource-list.png[link=self,window=_blank]

The *Credentials* panel on that page holds the two values the CLI needs. Click *Show credentials* to reveal the API key, and keep the URL beside it.

image::m5/orchestrate-credentials.png[link=self,window=_blank]

== Verify Orchestrate CLI is installed

The commands in this module use the watsonx Orchestrate ADK CLI. In a terminal in Bob, check whether it is already there:

[source,sh,role="copypaste"]
----
orchestrate --version
----

If that fails, install it:

[source,sh,role="copypaste"]
----
python3 -m pip install --upgrade ibm-watsonx-orchestrate
----

If the install also fails, ask your proctor.

== Point the CLI at your instance

Register the instance as an environment named `globex`, using the URL from the Credentials panel:

image::m5/orchestrate-env-add.png[link=self,window=_blank]

[source,sh,role="copypaste"]
----
orchestrate env add -n globex -u <the URL from the Credentials panel>
----

Then activate it:

[source,sh,role="copypaste"]
----
orchestrate env activate globex
----

When prompted with `Please enter WXO API key:`, paste the API key from the same panel from the Watsonx Orchestrate instance.

....
[INFO] - Environment 'globex' is now active
[INFO] - Active workspace: Global workspace.
....

Every `orchestrate` command from here on runs against that environment.
