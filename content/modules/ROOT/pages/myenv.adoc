[NOTE]
====
Keycloak serves two realms. `globex` holds the customer accounts the storefront and the chatbot sign in to. `internal` holds the workload clients -- the agent and the two MCP servers -- which Module 3 configures. Both are created when your environment is provisioned.
====

== Workshop Endpoints

These are services, not web consoles. Paste them into the MCP Inspector or into configuration.

|==================
| Service | URL | Notes

| Orders MCP server
| `\https://globex-store-mcp.{openshift_subdomain}/mcp`

| `\https://globex-complaints.{openshift_subdomain}/mcp`
